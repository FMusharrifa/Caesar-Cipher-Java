# Caesar-Cipher-Java
"Caesar Cipher 🔐

📌 Project Description

The Caesar Cipher is a classical encryption technique that encrypts messages by shifting each letter in the alphabet by a fixed number of positions.

This project was developed using Java in Apache NetBeans IDE. It demonstrates the basic concepts of cryptography, encryption, and decryption.

✨ Features

- Encrypt text using the Caesar Cipher algorithm.
- Decrypt encrypted messages.
- Use a shift value to control the encryption.
- Demonstrate basic text encryption and decryption.

🛠️ Technologies Used

- Java
- Apache NetBeans IDE

⚙️ How to Run the Project

1. Download or clone this repository.
2. Open Apache NetBeans IDE.
3. Select File → Open Project.
4. Select the downloaded Caesar Cipher project.
5. Click Run Project or press F6.

🔐 How It Works

The Caesar Cipher replaces each letter with another letter a fixed number of positions away in the alphabet.

Example:

- Original Text: "HELLO"
- Shift Value: "3"
- Encrypted Text: "KHOOR"
- Decrypted Text: "HELLO"

🎯 Learning Objectives

- Understand basic encryption and decryption.
- Practise Java programming.
- Learn the fundamentals of classical cryptography.
- Develop problem-solving skills.

⚠️ Limitations

The Caesar Cipher is a basic educational encryption method and is not secure enough to protect sensitive information.
